# Tanquilla La California Sur • Campaña de Recaudación Vecinal

Plataforma comunitaria de recaudación transparente para financiar la reparación urgente de la tanquilla vial en la Urbanización La California Sur, Caracas.

- **Meta presupuestada:** $600 USD (Marco, tapa de herrería pesada y mano de obra).
- **Base de datos en tiempo real:** Supabase (`tanquilla_aportes`).
- **Canales de aporte:** Pago Móvil (a tasa oficial BCV) y Efectivo (USD).
- **Panel de Administración:** Gestión, verificación y validación de aportes vecinales (`admin.html`).
- **Despliegue:** GitHub Pages.
